# 三平台酒店接口信息全集

> 目的：对照三家接口能返回哪些字段，重点看面积、房型、基础信息等维度。

## 一、飞猪 flyai（官方 CLI）

- **工具**：`flyai`（npm 包 `@fly-ai/flyai-cli`），`flyai search-hotel`
- **认证**：`flyai config set FLYAI_API_KEY <key>`；体验模式无需 Key 但价格打码
- **请求参数**：`--dest-name`（必填）、`--check-in-date`、`--check-out-date`、`--key-words`、
  `--hotel-stars`、`--hotel-bed-types`、`--max-price`、`--limit` 等
- **返回**：结构化 JSON，`data.itemList[]` 每家酒店字段如下：

| 字段 | 示例 | 说明 |
|---|---|---|
| name | 上海和平饭店 | 酒店名 |
| price | ¥3568 | 价格（正式 Key 下明码） |
| star | 五星级 | 星级 |
| address | 上海 黄浦区 南京东路20号 | 地址 |
| brandName | 雅高 | 品牌 |
| decorationTime | 2010 | 装修时间 |
| interestsPoi | 近南京路步行街 | 附近商圈/景点 |
| latitude / longitude | 31.23902 / 121.489468 | 经纬度 |
| mainPic | https://img.alicdn.com/… | 主图 URL |
| detailUrl | https://router.feizhu.com/… | 详情页链接 |
| shId | 10047991 | 飞猪酒店 ID |
| rate | null | 评分（常为空） |
| commissionMoneyYuan | null | 佣金（常为空） |

- **缺失维度**：❌ 房间面积、❌ 房型列表、❌ 床型、❌ 取消政策、❌ 早餐信息、❌ 设施详情
- **口径**：酒店级聚合价，非房型级；评分经常为空。

## 二、美团 ht-ai（官方 CLI）

- **工具**：`ht-ai`（npm 包 `@meituan-travel/ht-ai`），`ht-ai query --query "<自然语言>"`
- **认证**：`MEITUAN_HT_TOKEN` 环境变量，或 `~/.config/meituan-travel/config.json` 的 `key` 字段
- **请求**：自然语言 query（如"上海和平饭店10月16日入住10月17日离店基础房型价格"）
- **返回**：自然语言 Markdown（非结构化），信息维度如下：

| 维度 | 示例 | 说明 |
|---|---|---|
| 房型名 | 费尔蒙金尊客房 | ✅ 有 |
| 床型 | 1张特大床2米 | ✅ 有 |
| 面积 | 49㎡ | ✅ 有 |
| 入住人数 | 2人入住 | ✅ 有 |
| 价格 | 1晚共￥48XX / ￥4897 | ✅ 有，但有时脱敏（￥XX） |
| 取消政策 | 限时免费取消 | ✅ 有 |
| 早餐 | 含两份早餐 | ✅ 有 |
| 房型图片 | http://p1.meituan.net/… | ✅ 有（图片 URL） |
| 预订链接 | http://dpurl.cn/… | ✅ 有（短链） |
| 确认速度 | 确认较快 | ✅ 有 |
| 描述文本 | 49㎡宽敞大床房… | ✅ 有 |

- **缺失维度**：❌ 结构化字段（全靠正则解析）、❌ 酒店级评分/星级、❌ 经纬度
- **口径注意**：
  - 价格有时脱敏（￥48XX），同一查询前后两次结果可能一次明码一次脱敏；
  - 日期约束不一定被严格执行，返回的可能是近期通用价；
  - 同一酒店不同来源面积有差异属正常（如美团 49㎡ vs 携程 45㎡）；
  - 无结构化产品类型字段，默认返回可能混有团购口径；query 中明确要求"日历房、排除团购"，
    但无法独立验证。美团侧价格仅作参考量级。

## 三、携程问道（官方 skill 接口，匿名）

- **接口**：`POST https://wendao-skill-prod.ctrip.com/skill/query`
- **认证**：无（匿名可用）
- **请求**：`{"query": "<自然语言问句>"}`，`Content-Type: application/json`
- **返回**：Markdown 文本（LLM 生成），信息维度如下：

| 维度 | 示例 | 说明 |
|---|---|---|
| 酒店名 | 上海和平饭店 | ✅ 有 |
| 价格 | 3,568元起 / 200-350元 | ✅ 有，但为区间/参考价口径 |
| 房间面积 | 45平方米 | ✅ 有（问房型详情时给） |
| 床型 | 特大床，可住2成人+1儿童 | ✅ 有 |
| 含早选项 | 不含早/单早/双早 | ✅ 有 |
| 取消政策 | 不可取消 | ✅ 有 |
| 房间设施 | BOSE音响、浴缸… | ✅ 有 |
| 酒店设施 | 泳池、健身房、Spa… | ✅ 有 |
| 用户评分 | 4.8分 | ✅ 有 |
| 入住/退房政策 | 15:00后入住、12:00前退房 | ✅ 有 |
| 预订链接 | https://m.ctrip.com/webapp/hotels/detail?… | ✅ 有 |

- **缺失/不稳定**：❌ 结构化字段、⚠️ 价格为参考价非保证可订价、⚠️ 返回格式每次略有差异
- **口径注意**：匿名调用低频可用；该端点未完全公开文档化，可能调整。

## 四、对照总结：面积与基础信息

| 维度 | 飞猪 | 美团 | 携程问道 |
|---|---|---|---|
| 房间面积 | ❌ | ✅ | ✅ |
| 床型 | ❌ | ✅ | ✅ |
| 房型列表 | ❌ | ✅ | ✅（问详情时） |
| 早餐信息 | ❌ | ✅ | ✅ |
| 取消政策 | ❌ | ✅ | ✅ |
| 设施详情 | ❌ | ⚠️（描述文本带） | ✅ |
| 酒店评分 | ⚠️（常空） | ❌ | ✅ |
| 星级 | ✅ | ❌ | ✅（文本中） |
| 经纬度 | ✅ | ❌ | ❌ |
| 品牌 | ✅ | ❌ | ✅（文本中） |
| 价格 | ✅（明码） | ✅（有时脱敏） | ⚠️（区间/参考价） |
| 结构化程度 | 高（JSON） | 低（Markdown） | 低（Markdown） |

**结论**：要面积和房型基础信息，看美团和携程问道；要结构化酒店列表和稳定价格，看飞猪。
三家互补，没有一家全覆盖。
